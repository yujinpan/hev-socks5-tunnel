# HevSocks5Core

Client-only SOCKS5 library vendored into this branch.

**Features**
* IPv4/IPv6 destinations. (SOCKS address types)
* Standard `CONNECT` command.
* Standard `UDP ASSOCIATE` command.
* Authentication handshake is skipped (CONNECT / UDP ASSOCIATE are still sent).

**Dependencies**
* HevTaskSystem - https://github.com/heiher/hev-task-system
